# Assets Directory

This directory contains runtime assets that are bundled with the Electron application.

## Structure

```
assets/
├── icons/          # Runtime icons (different from build icons)
├── images/         # Application images and graphics
├── sounds/         # Notification sounds and audio files
└── data/           # Static data files, configurations, etc.
```

## Notes

- Keep assets optimized for size
- Use appropriate formats (PNG for images, MP3/OGG for audio)
- Consider platform-specific assets if needed
- Assets are included in the final application bundle
